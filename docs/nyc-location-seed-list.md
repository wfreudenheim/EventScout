## Notes on Expansion

This list is intentionally wide. The system doesn't need to successfully scrape every one of these on day one. The seed list gives agents a large surface area to work across, and relevance scores will naturally surface which venues produce the most interesting events over time.

The **Institution Discovery Agent** should run monthly and look for:
- New project spaces or galleries that have opened recently
- University departments or labs with public event programming
- Pop-up event series on Eventbrite or Luma matching interest keywords
- Venues mentioned on cal.red or other community calendars that aren't yet in the registry
- Ridgewood/Bushwick/Williamsburg neighborhood-specific searches for new spaces
- Apartment galleries and itinerant projects (these open and close frequently, worth periodic sweeps)
- Orgs like Do Not Research that host events at various venues (track the org, not a fixed location)

When the Discovery Agent finds a candidate, it should create a "pending" entry in the Location Registry with whatever metadata it can gather, flagged for manual review.
